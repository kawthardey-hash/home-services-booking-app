
# 🧹 Home Services Booking App

A modern cross-platform mobile application built with **Flutter & Dart** that allows users to seamlessly explore, book, and manage home maintenance and cleaning services.

---

## 🚀 Features

- 🔐 **User Authentication**: Secure sign-up and login functionality.
- 🛠 **Service Categories**: Browse through various services (Cleaning, Plumbing, Electrical, Maintenance).
- 📅 **Easy Booking System**: Select preferred dates, time slots, and service providers.
- 💳 **Order Tracking & History**: Real-time status updates on active and completed service requests.
- 🎨 **Clean UI/UX**: Designed following modern mobile design patterns.

---

## 🛠 Tech Stack & Tools

- **Framework**: [Flutter](https://flutter.dev)
- **Language**: [Dart](https://dart.dev)
- **State Management**: BLoC / Provider
- **Backend / APIs**: REST API / Firebase
- **Architecture**: Clean Architecture
